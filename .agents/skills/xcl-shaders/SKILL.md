# Shaders

Pipeline: container (`gpu/xbox.rs`: DXIL `NOBC` → XDAT → XBCH v3 → FSSM) → decode (`gpu/rdna2.rs` plus `rdna2_xbox.rs` console opcodes) → `gpu/recomp` HLSL → `dxc.rs` DXIL.

`rdna2_spec.rs` is generated by `scripts/gen_rdna2.py` from AMD's machine-readable ISA. Console opcodes that gfx10.3 removed (`v_mac_f32`, `v_madmk_f32`, `v_madak_f32`, `v_mad_f32`) stay in `rdna2_xbox.rs` on free opcode numbers. A literal is fetched when any src field is 255, including unused ones (`v_nop ; lit`).

Recompiler model (`gpu/recomp/mod.rs`): scalar branches, structured `if` / loops where possible, skip flags otherwise. SGPRs uniform, VGPRs per lane under EXEC, ballot via `WaveActiveBallot`, cross-lane via `WaveReadLaneAt`. Modes: `Kernel` (tests), `Vertex`, `Pixel`, `Mesh` (CS wave64 plus `mesh_passthrough`), `Geometry` (ES+GS in one CS), compute ABI from the FSSM descriptor. Flat memory is `ByteAddressBuffer` `mem`; user SGPRs come from `io`.

`dxc::compile` forces `-O0` above 256 KB of HLSL. DXC 1.8+ is the README recommendation (`XCL_DXC_DIR`). Cache: `compile_cached`.

Wave64 on 32-lane GPUs: `docs/wave64-on-wave32.md` and `upper_lanes.rs`. Do not delete the second half to make NVIDIA "pass".

Tools: `xcl disasm`, `xcl shaders --recomp --example MNEMONIC --compile 64`. Dumps of captured shaders only when `XCL_DUMP_SHADERS=1`.

A new mnemonic belongs in `emit.rs` with a GPU test in `gpu/recomp/tests.rs` that encodes via `rdna2::encode` and checks the lane result. Unsupported ops increment the counter and become a comment; do not emit a wrong opcode as if it were done.
